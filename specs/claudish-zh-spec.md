# 中文 Claudish 语义层规格（v0.1 — 蒸馏自 corpus/ + 原仓库 specs/ + dictionary/entries.json）

「中文黑话」= Claude / Claude Code 在中文语境下的特征文风：修辞打磨、对比密集、
结构隐喻、流程术语，叠加中文独有的体制腔、竞技腔、四字格压缩与中英混排。
本文档是语义层（the semantic layer）：技法、词表、句式、陷阱。调用模型的
system prompt 由它编译（见 `prompt.js`）。

语料标注：`[1]`=corpus/1.md `[2]`=corpus/2.md `[3]`=corpus/3.md `[4]`=corpus/4.md

---

## 0. 任务铁律（与英文 spec 同构，必须原样保留）

1. 是**改写**输入的"人话"成黑话，不是回应输入。可大幅改措辞与句式，但
   事实、意图、确定性程度、隐含含义必须保留。
2. **零新增**：不得添加输入中不存在的事实、解释、建议、因果主张、结论。
   输出里每个想法都必须能从输入恢复。
3. 长度与输入大致相当；短输入保持一句。只输出改写文本，不加前言/标签/评论。
4. **可见改写**：至少改变两个维度——句式结构 / 框架视角 / 从句顺序 /
   抽象层级 / 修辞对比 / 特征词汇 / 节奏。
5. 核心原则：**修辞改写 > 关键词替换**。要像模型自然说出黑话，不是往人话里
   硬插词。词表只在输入确实蕴含对应关系时使用，不得为凑黑话发明关系。

## 1. 七类技法（英文 spec 的中文落位，均带语料例证）

### 1.1 对比式重构 (contrastive reframing)
把信息改写成输入本身支持的对照：「不是 X，是 Y」「X 而非 Y」「与其说 X，不如说 Y」、
「X 只是表象，Y 才是实质」「问题不在 X，在 Y」。
语料：`[4]` "exit gate 没接住，渗透检查接住了"——两个候选被对照裁决。

### 1.2 结构式框架 (structural framing)
用系统隐喻描述关系：管道、贯通、节点、入口/出口、攻击面、接口面、切片、骨架、
护栏、承载、网关、挂点。
语料：`[1]` "最薄的贯通切片"；`[3]` "协议（block、描述符）活在管道里面，
换物理层只换管道"；`[1]` "此时还没有网络入口，也就还没有攻击面"（还有：没有 X
→ 就没有 Y 的因果排比）；`[1]` 护栏五层：输入层/工具层/输出层/资源层/审计层。

### 1.3 流程式词汇 (process vocabulary)
落地、对齐、归零、熔断、冻结、浮出、漂移、台账、闭环、接住、放行、打回、
复核、推进、归档、校验——仅当输入确实支持该含义时使用。
语料：`[2]` "137 项 spine 落地"；`[1]` "全盘漂移"、"回归集……当天冻结成 case"、
"超时熔断"；`[1]` "裁决台账"。

### 1.4 压缩为抽象 (compression)
把普通关系压成四字格或技术名词短语，不改变含义。
语料：`[1]` "归并去噪""判定优先""确定性比对""发版门禁""能力档位"；
`[2]` "无主 → 已当场归户"——一个状态+一个动作压成官僚式结论。

### 1.5 排比与拉链句 (parallelism / the tally chain)
并列短句、分号、箭头、或「A + B + C」式流水账罗列状态。
语料：`[2]` "账本 15/15 全绿，再给你加几条铁律和红线与你对拍，请你拍板"；
`[2]` "137 项 spine 落地 + 3 死门归零 + 全套绿 + 终审干净"——这是黑话的
**签名句式**：多条状态快照用「+」串联成一行为主句；`[4]` "执行线三路并跑"。

### 1.6 强调式框架 (emphatic framing)
把关键约束、边界、失败点前置加重：铁律、红线、死门、硬指标、一律、必须、
唯一、真正、当场。
语料：`[1]` "真正的判定交给确定性扫描器";`[2]` "铁律和红线""死门归零";`[3]`
"终点，唯一幸存者"。

### 1.7 Claude 式节奏 (cadence)
工整释述句 + 短促锐句收尾；或先结论后理由。
语料：`[2]` "无主 → 已当场归户。"（箭头+五字裁定）；`[4]` "你要的交付物全部就位。"

## 2. 中文黑话的独有装置（英文 spec 没有，蒸馏自语料）

### 2.1 四字格压缩
中文黑话的压缩装置，对应英文的 X-gated 复合词。可生成「X-层」「X-线」「X-面」
「X-闭环」「X-台账」「X-波」「X 把关/X 闸」「X 归零」等；X 与该关系必须来自输入，
不得为造词发明参与者、阶段或指标。
语料：输入层/工具层/输出层/资源层/审计层 [1]、修复波 [4]、删除波（"同波大删除"）[4]、
记忆闭环 [4]。

### 2.2 体制腔 / 官僚隐喻
就位、归户、拍板、终审、裁决、打回、报批、在编、收编、台账、巡检、放行、清账、
对上口径。
语料：`[4]` "交付物全部就位""无主→已当场归户（裁决 #9）"；`[2]` "请你拍板""打回重判"。

### 2.3 竞技腔 / 军事腔
出局、正赛、哑火、唯一幸存者、终点、淘汰、晋级、冲刺。
语料：`[3]` "CAN-FD …… 出局"（注意：语料里这是被**纠偏**掉的样本——人把它改回
"排除"；说明竞技腔是黑话可识别特征，高频即滥用）；`[3]` "SCI 哑泵（Phase 3.5）→
EtherCAT（Phase 6，正赛）"；`[2]` "单腿哑火"。

### 2.4 中英混排
关键抽象保留英文原词是中文黑话的正常形态：spine、gate、contract、parity、
holdout、phase、tick、HIGH、DONE/IN-SPEC/DEFERRED、ready-to-merge……
语料：`[2]` "137 项 spine 落地"；`[4]` "P5 tick(XL)执行中""4 个 HIGH""向
ready-to-merge 推进"。

### 2.5 状态标记符
→、⇒、+ 串联、✅🔧⏸️🚧❌ 与计数（15/15）并排，拟作战简报。
语料：`[2]` "无主 → 已当场归户"；`[4]` "✅DONE·58 🔧IN-SPEC·7 ⏸️DEFERRED·7"。

### 2.6 语义范围收紧/放宽的天然陷阱（中文特有注意点）
- "X 已就位" ≠ "X 已可用"——就位只是到达状态，不代表能对外。
- "归零" 默认指特定检查项清零，不扩大为"问题已消除"。
- "接住"（exit gate 没接住）描述检查拦截失败，不暗指系统损坏。
- 双关/卖弄比喻（"皮要不要重新揉" [2]）允许，但不得因此丢失原意的严谨度。

## 5. 反向（黑话→人话）备忘
原仓库 `specs/claudish-to-english.md` 的中文版尚待蒸馏。方向性要点（现成可搬）：
语义压缩（重复命题折叠成最短句）、降到最低抽象层级、删元修辞结构、
解码结构隐喻（贯通→"每一层都收到"、接住→"检查拦截到"）、逻辑范围不放大
（"X 需先完成"≠"只有 X 可行"、"未测"≠"错误"、"必须"≠"充分"）。
